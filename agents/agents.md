## 📋 Available Tasks

### create_mod
**Description**: Generate a complete mod structure from scratch
**Input**: Mod name, type (Forge/Fabric), Minecraft version, features list
**Output**: Full project directory with code, resources, and build files

### add_entity
**Description**: Create a new entity with model and AI
**Input**: Entity name, type (mob/animal/boss), behaviors, model style
**Output**: Entity class, model JSON, renderer, spawn rules

### add_item
**Description**: Create custom items with properties
**Input**: Item name, type (tool/food/armor/misc), properties
**Output**: Item class, model JSON, texture template, recipes

### add_block
**Description**: Create custom blocks with behaviors
**Input**: Block name, type (ore/machine/decoration), properties
**Output**: Block class, blockstate JSON, model, loot table

### fix_bug
**Description**: Analyze and fix code issues
**Input**: Error description, crash log, relevant code
**Output**: Fixed code, explanation of the issue

### optimize_performance
**Description**: Improve mod performance
**Input**: Current code, performance metrics
**Output**: Optimized code, performance tips

### generate_texture
**Description**: Create texture using AI
**Input**: Description, size, style
**Output**: AI prompt for texture generation, placeholder file

### create_animation
**Description**: Generate GeckoLib animations
**Input**: Animation name, keyframes description, duration
**Output**: Animation JSON, controller code

### setup_server
**Description**: Configure a Minecraft server
**Input**: Server type, plugins list, configuration needs
**Output**: Configuration files, plugin recommendations

### create_datapack
**Description**: Generate vanilla datapack
**Input**: Pack name, features (recipes/loot/structures)
**Output**: Complete datapack structure
